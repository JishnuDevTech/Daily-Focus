# Daily Focus

[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

Daily Focus is a simple and effective productivity web app designed to help users stay focused on their daily tasks and goals. It emphasizes clarity, consistency, and a distraction-free experience across both mobile and desktop devices.

## About

Daily Focus is built to help users prioritize what matters each day.  
By keeping tasks clear and progress visible, the app encourages users to stay consistent and focused without overwhelming them with unnecessary features.

---

## Features

- Create and manage daily tasks  
- Minimal and distraction-free interface  
- Responsive design for mobile and desktop  
- Smooth and intuitive user experience  
- Fast performance with clean UI

## Usage

1. Open the app in your browser  
2. Add your daily tasks or focus items  
3. Track progress throughout the day  
4. Stay organized and consistent
